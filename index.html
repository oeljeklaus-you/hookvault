HOOKVAULT PRIVACY POLICY

Privacy Policy

Effective date: May 7, 2026

HookVault is a Chrome extension that helps users save and organize public posts from X/Twitter into a local swipe file.

1. What HookVault Does

HookVault lets users save public posts from x.com and twitter.com, along with related metadata such as source links, post text, author information, tags, notes, media type, and status.

2. Information HookVault Collects

When a user chooses to save a public post, HookVault may collect and store:

  • Source URL of the saved post
  • Post text visible on the page
  • Author name and handle when available
  • Media type and visible media URLs available from the page DOM
  • User-added tags
  • User-added notes
  • Status such as used or unused
  • Created and updated timestamps

3. How HookVault Uses Information

HookVault uses this information only to provide its core functionality, including:

  • Saving public X/Twitter posts into a local swipe file
  • Helping users search, filter, organize, and review saved items
  • Allowing users to export their saved library as CSV or JSON

4. Where Information Is Stored

HookVault stores saved data locally in the user’s browser using chrome.storage.local.

HookVault does not require an account and does not send saved posts, notes, or library contents to the developer’s servers.

5. Sharing of Information

HookVault does not sell, rent, or share saved library data with third parties.

Data is only exported or copied when the user explicitly chooses to do so.

6. Permissions and Site Access

HookVault requests the following permissions only to support its user-facing features:

  • storage: to store saved items locally in the browser
  • activeTab: to interact with the current tab when the user uses the extension
  • https://x.com/* and https://twitter.com/*: to run only on X/Twitter pages and allow users to save public posts

7. What HookVault Does Not Do

  • HookVault does not download protected videos or media files
  • HookVault does not bypass paywalls, DRM, or login restrictions
  • HookVault does not access private content
  • HookVault does not provide cloud sync, advertising, or data resale

8. Data Security

Because HookVault stores saved library data locally in the browser, users remain in control of their saved content on their device. If future versions of HookVault introduce remote services, this privacy policy will be updated before those services are used.

9. Changes to This Policy

This privacy policy may be updated from time to time to reflect product, legal, or policy changes. The latest version will be posted at this URL.
